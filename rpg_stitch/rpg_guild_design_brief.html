# RPG Guild Screen Design Brief ## Project Overview `RPG Guild` is a web service that makes guild/team management feel like an "RPG Guild Management Console." It bridges the gap between B2C gaming and B2B/SaaS management tools. ## Core Design Goals 1. **Strong Game Aesthetic, Maintained Usability:** HUD-style interface, guild lobby feel, but with clear operational clarity. 2. **Focus on Rank, Reward, and Progression:** Emphasis on growth tracking and "Status Boards" rather than simple lists. 3. **Distinct Screen Roles:** Landing (World Entry), Hub (Status), Members (Roster), Missions (Quest Board), Logs (History). ## Visual Direction - **Keywords:** Tactical Fantasy, Guild Command Center, Reward-driven HUD, Arcane Glass + Metal Frame. - **Tone:** Sharp, sophisticated system HUD; metallic textures for rewards; high-end game lobby/raid waiting room vibe. - **Avoid:** Generic SaaS dashboards, overly cute/casual mobile styles, or excessive neon cyberpunk. ## Color Palette - **Background:** Deep Navy / Slate (Dark mode only). - **Primary (Amber):** Rewards, Ranks, Major Promotions. - **Secondary (Cyan):** System Info, Progress, Navigation. - **Warning (Rose):** Danger, Costs, Depletion. ## Layout & Screens 1. **Global Header:** Brand emblem focus, player status panel. 2. **Guild Hub:** Main dashboard, "Command Center" view. 3. **Member Page:** "Party Slot" management, character cards with rank/job badges. 4. **Mission Page:** Quest board aesthetic, reward distribution flow. 5. **Logs Page:** History report, retrospective dashboard with charts. ## Mobile Requirements - Mobile-first priority for HUD and navigation. - Prioritize actionability and layout restructuring over simple compression.
